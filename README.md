## 这是什么

一个**开源的结构化探佚推理系统**。我们把曹雪芹在《红楼梦》前80回中埋下的每一条伏笔、脂砚斋留下的每一条批语、红学家数十年的探佚成果，转化为**可计算、可验证、可追溯的结构化数据**。

核心假设：**曹雪芹已写完《红楼梦》全书**（110回），后30回因"迷失"而佚失。但大量伏笔和脂批提供了足够的约束条件，这些约束本质上定义了一个**逻辑推理问题**——我们可以从证据链出发，推断哪些结局是必然的，哪些组合是矛盾的。

## 快速开始

### 浏览数据（无需安装）

```bash
cd public
python3 -m http.server 8000
# 打开 http://localhost:8000
```

在页面中浏览人物结局、伏笔索引、约束图和事件时间线。

### 运行推理引擎

```bash
cd src/core
python3 engine.py
```

输出包括：
- 人物结局一致性检查
- 后三十回事件拓扑排序
- 约束传播演示

## 核心方法

1. **伏笔结构化** — 将前80回每条伏笔与脂批按统一格式录入
2. **约束图构建** — 建立伏笔间的5种逻辑关系
3. **约束传播** — 给定一条伏笔为真，自动传播影响
4. **一致性验证** — 检查结局假设是否与约束兼容
5. **拓扑排序** — 基于时间顺序重建事件序列

### 五种约束类型

| 类型 | 含义 | 示例 |
|------|------|------|
| 🔗 必然导致 | 前提成立时结论必然成立 | 绛珠"还泪"设定 → 黛玉泪尽而亡 |
| ✅ 支持 | 前提增加结论可信度 | "冷月葬花魂" → 支持沉湖说 |
| ❌ 矛盾/互斥 | 两个结论不能同时为真 | "万苦不怨"之死 vs 焚稿断情 |
| ⏱️ 时间顺序 | A必须在B之前发生 | 元春之死 → 贾府之败 |
| 🔀 因果依赖 | A是B的前提条件 | 元春失宠 → 贾府失去政治保护 |

### 确定性评级

- **确定** — 脂批直接提示，或文本内逻辑必然
- **极有可能** — 多条独立证据链汇聚
- **有可能** — 合理推测但证据不足
- **存疑** — 待更多证据验证
