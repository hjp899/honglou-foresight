# 📝 续写实验 · Continuation Experiments

> 分支定位：基于约束推导，生成后三十回的结构化章回大纲。**不是写续书，而是用数据自动推导"曹雪芹在每回应该写了什么"。**

---

## 🎯 这个分支做什么

主分支（`main`）提供的是伏笔数据库和约束推理引擎——相当于"证据库"和"推理工具"。这个分支做的事不同：**用推理工具生成一个可看的产出物**。

具体来说：

1. 从主分支的 `data/events.json` 加载 22 个重建事件
2. 按推算回目聚类到第 81-110 回
3. 对每回生成结构化大纲，包括：
   - **回目**（仿曹雪芹风格的双句对仗回目）
   - **出场人物**（从人物数据库自动匹配）
   - **呼应伏笔**（此回收束了前文哪些伏笔）
   - **人物命运推进**（谁在此回死亡/出嫁/出家/远行）
   - **置信度评估**（高/较高/中等/低）
4. 输出完整的后三十回章回大纲

## 🤝 需要你做什么

这个分支当前的 22 个事件覆盖了后三十回的主要节点，但仍有 **8 回的内容为空白**（第 97-99、101、103、106-108、110 回）。这些回目在现存脂批和伏笔线索中几乎没有踪迹。

**你能贡献的：**

1. **补全空白回目** — 如果你发现了新的脂批或文本伏笔线索（哪怕是很间接的），提交到 `data/foreshadowing_batch3.json`
2. **改进回目生成** — 如果你觉得某个回目的措辞不够"曹雪芹"，提交改进建议
3. **补全程高本情节数据库** — `chenggao_diff.py` 目前只录入了程高本的摘要。你可以逐回录入更详细的情节描述，存入 JSON 数据库
4. **验证约束满足** — 检查大纲中的某一回是否与你已知的研究成果矛盾
5. **添加人物出场校验** — 如果某人物在前一回已经死亡，后面就不能再出现——这类逻辑约束目前引擎还未完全覆盖

## ⚠️ 重要声明

- 本分支的产出物是**实验性的结构化大纲**，不是曹雪芹原稿的还原
- 回目和场景描述由算法自动生成，不代表曹雪芹的实际文字
- 所有置信度 < 40 的推理均标注了"推测性填充"
- 空白的 8 回暂时留白——等待社区发现新的脂批或文本证据
