# ⚖️ 程高本对比分析 · Cheng-Gao Diff

> 分支定位：用约束推导的结局框架，逐回对照程高本后四十回，**量化两者之间的偏离程度**。回答一个困扰红学界两百年的学术问题：程高本续书到底在多大程度上违背了曹雪芹的原意？

---

## 🎯 这个分支做什么

主分支提供的是"曹雪芹的原意是什么"（通过伏笔约束推导出来的结局框架）。这个分支做的事：**把程高本后四十回的每一回，和约束推导框架逐回对照，找出每一个矛盾点，给出一个量化的偏离度评估。**

不做主观评价（"程高本写得好不好"不是一个可量化的问题），只做客观对比：程高本在这一回写的事情，符合曹雪芹伏笔约束的有几处，违反的有几处。

---

## 🧮 核心方法

### 四类差异标记

| 类型 | 图标 | 含义 | 示例 |
|------|------|------|------|
| **严重矛盾** | ❌ | 程高本此回直接违反刚性约束 | 第 86 回写元春"病逝"→违反 FS-017 脂批"《长生殿》伏元妃之死=赐死" |
| **显著扭曲** | 🔄 | 事件本身发生了但细节被改写 | 第 93 回程高本写了抄家，但时间线/原因/过程与脂批提示不符 |
| **完全缺失** | ➖ | 约束推导有明确事件，程高本完全跳过 | 狱神庙（茜雪小红探慰宝玉）在程高本中完全消失 |
| **续书新增** | ➕ | 程高本写了约束推导中没有的事件 | 调包计（宝玉被骗娶宝钗）没有任何脂批或伏笔支持 |

### 偏离度量化公式

每回的偏离度 = (严重矛盾数 × 3 + 显著扭曲数 × 2 + 完全缺失数 × 1.5) / 本回推导事件总数

整体偏离度 = 所有回偏离度的均值

**当前结果：整体偏离度 = 100%（严重偏离）**

### 核心矛盾总结

程高本在**四个最关键的节点**上全面违反了曹雪芹原稿的刚性约束：

1. **黛玉之死**：程高本写她焚稿含恨→脂批说"万苦不怨"，泪尽非怨恨
2. **元春之死**：程高本写她痰厥病逝→脂批《长生殿》点明她是被赐死的
3. **宝玉结局**：程高本让他中举后才出家→脂批说"悬崖撒手"，且宝玉"于国于家无望"不可能中举
4. **全书结局**：程高本以"沐皇恩""兰桂齐芳"收场→脂批说全书最后一句是"落了片白茫茫大地真干净"

## 🤝 需要你做什么

### 🔴 高优先级

1. **逐回录入程高本完整情节** — 目前引擎只录入了摘要级别的简述（如"元春染恙。黛玉吐血"）。需要志愿者**逐回录入程高本的详细情节**（含出场人物、关键对话、事件因果链），存入结构化的 JSON 数据库（`data/chenggao_full_plots.json`）。录入越详细，对比引擎的精确度越高。

2. **同一事件的多种续书版本对比** — 除了程高本，还有87版电视剧、2010版电视剧、刘心武续书、陈学军续书等版本。每个版本的同一回可以平行对比，得出"哪个续书版本最接近曹雪芹原意"的量化排名。

3. **回溯验证程高本的优点** — 目前的差异分析偏向批评程高本。但也需要客观收录程高本**符合约束推导**的情节（如鸳鸯殉主、惜春出家、刘姥姥救巧姐等少数吻合点），给出平衡的评估。

### 🟡 中优先级

4. **差异分类细化** — 目前的四类标记（矛盾/扭曲/缺失/新增）比较粗略。可以增加子类：如"时间线错位"（事件发生了但时间不对）、"人物替换"（事件本身是对的但参与人物被替换了）、"动机改写"（事件相同但人物动机被改了）

5. **可视化对比图表** — 用一个前端页面展示逐回对比结果，左侧显示约束推导大纲，右侧显示程高本对应内容，中间用颜色标注差异程度。参考 GitHub diff 的风格。

### 🟢 低优先级

6. **学术引用格式化** — 为每条差异标注对应的学术论文引用（如蔡义江《论红楼梦佚稿》第 X 章、梁归智《石头记探佚》第 Y 节），使报告具备学术引用价值。

## ⚠️ 重要声明

- 本分析**仅基于约束推导系统的量化框架**，不构成对程高本续书文学价值的否定
- 程高本的传播功绩（使《红楼梦》以完整形态流传至今）和历史地位是另一个独立的问题
- 程高本中少量与约束推导吻合的情节（鸳鸯殉主、惜春出家、刘姥姥救巧姐等）可能暗示这些回中**含有曹雪芹原稿的残片**
- 本引擎目前只能检测"程高本做了什么违反了约束"，不能回答"程高本为什么会这么写"——后者涉及续书者的创作动机、清代政治环境、读者审美期待等复杂历史因素，不在本引擎的量化范围内
