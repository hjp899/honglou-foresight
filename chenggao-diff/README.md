# 程高本对比分析分支

## 目标

用约束推导的结局框架，逐回对照程高本后四十回，量化两者之间的偏离程度。回答一个学术问题：程高本续书到底在多大程度上违背了曹雪芹的原意？

## 核心思路

1. 加载约束推导的 22 个重建事件（每个标注了推算回目）
2. 手动录入程高本后四十回的逐回关键情节摘要
3. 逐回对比：程高本写了什么 vs 约束推导认为应该写什么
4. 标记差异类型：矛盾（违反刚性约束）、缺失（程高本跳过）、新增（续书者原创）、扭曲（有对应但细节不符）
5. 量化整体偏离程度

## 关键发现摘要

| 冲突类型 | 严重程度 | 程高本回目 | 违反的约束 |
|---------|---------|-----------|----------|
| 黛玉之死 | 严重 | 第90回 | 焚稿含恨 vs 万苦不怨 |
| 元春之死 | 严重 | 第86回 | 病逝 vs 政治赐死 |
| 宝玉结局 | 严重 | 第100回 | 中举后出家 vs 悬崖撒手 |
| 全书结局 | 严重 | 第109回 | 兰桂齐芳 vs 白茫茫大地真干净 |

**总体评估：严重偏离 (100%)** —— 量化支持了红学界主流立场（程高本后四十回为伪续）。

## 实现

`chenggao_diff.py` — 逐回差异对比引擎。输出结构化 JSON 报告。

## 使用方法

```bash
cd src/branches
python3 chenggao_diff.py
```

## 注意

程高本后四十回情节摘要是手动录入的（非自动爬取），可能存在疏漏。欢迎社区补充和修正程高本情节数据库。

本分析仅基于约束推导系统，不代表对程高本续书文学价值的否定——程高本的传播功绩和历史地位是另一个独立的问题。
