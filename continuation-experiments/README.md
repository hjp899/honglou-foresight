# 续写实验分支

## 目标

基于约束推导，生成后三十回的结构化章回大纲——不是写续书，而是用数据自动推导"曹雪芹在每回应该写了什么"。

## 核心思路

1. 从 `data/events.json` 中加载 22 个重建事件
2. 按推算回目聚类到第 81-110 回
3. 每回标注：出场人物、呼应了前文哪些伏笔、推进了哪些人物命运、该回的约束满足率
4. 生成仿曹雪芹风格的双句对仗回目（基于人物名 + 事件关键词的组合生成）

## 示例输出

```
第85回 林黛玉泪尽归离恨　贾宝玉衔悲入囹圄
  置信度: 高
  出场: 林黛玉、贾宝玉、紫鹃、王夫人
  呼应伏笔: FS-002(绛珠还泪) FS-013(芙蓉诔实诔黛玉) FS-026(葬花吟)
  人物命运推进: 黛玉归天（第85回，泪尽夭亡）
  约束满足: 本回满足了 "黛玉之死不能是焚稿断情" 的刚性约束
```

## 实现

`continuation_experiment.py` — 后三十回章回大纲生成器。输入伏笔约束图 + 事件拓扑排序，输出完整的 30 回大纲 JSON。

## 使用方法

```bash
cd src/branches
python3 continuation_experiment.py
```

输出 JSON 保存在 `outputs/chapter_outline.json`。

## 注意

本分支不做文本续写，只做结构化大纲。回目和场景描述基于数据库中的伏笔和事件记录自动生成，不代表对曹雪芹原稿的逐字还原。
