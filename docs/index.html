关于这个项目

开源的结构化探佚推理系统。把曹雪芹在前80回中埋下的每一条伏笔、脂砚斋留下的每一条批语、红学家数十年的探佚成果转化为可计算、可验证、可追溯的数据。

核心假设：曹雪芹已写完《红楼梦》全书（110回），后30回因借阅者"迷失"而佚失。大量伏笔和脂批提供了足够的约束条件——这些约束本质上定义了一个逻辑推理问题。

与 MiroFish（多智能体仿真）和 OpenStory（角色沙盒演化）不同，本项目走证据链路线：逐条伏笔 → 约束图 → 逻辑传播 → 一致性验证。
