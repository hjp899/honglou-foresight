关于这个项目

开源的结构化探佚推理系统。把曹雪芹在前80回中埋下的每一条伏笔、脂砚斋留下的每一条批语、红学家数十年的探佚成果转化为可计算、可验证、可追溯的数据。

核心假设：曹雪芹已写完《红楼梦》全书（110回），后30回因借阅者"迷失"而佚失。但大量伏笔和脂批提供了足够的约束条件——这些约束本质上定义了一个逻辑推理问题。

与 MiroFish（多智能体社会仿真）和 OpenStory（角色沙盒演化）不同，本项目走证据链路线：逐条伏笔 → 约束图 → 逻辑传播 → 一致性验证。

🔬 核心方法
  1. 伏笔结构化 — 将前80回中的每一条伏笔与脂批按统一格式录入
  2. 约束图构建 — 建立伏笔间的逻辑关系：必然导致、支持、矛盾/互斥、时间顺序、因果依赖
  3. 约束传播 — 给定一条伏笔为真，自动传播其对其他伏笔/结局的影响
  4. 一致性验证 — 检查一组结局假设是否与所有已知约束兼容
  5. 拓扑排序 — 基于时间顺序约束对事件进行排序，重建后三十回的事件序列
