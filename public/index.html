关于这个项目

这是一个开源的结构化探佚推理系统。不同于用大语言模型直接"续写"红楼梦结局，我们做的是把曹雪芹在前80回中埋下的每一条伏笔、脂砚斋留下的每一条批语提示、红学家们数十年的探佚成果，转化为可计算、可验证、可追溯的数据。

核心假设是：曹雪芹已经写完了《红楼梦》全书（110回），后30回因借阅者"迷失"而佚失。但大量伏笔和脂批提供了足够的约束条件，这些约束本质上定义了一个逻辑推理问题——哪些结局组合是逻辑一致的，哪些是矛盾的？

与 MiroFish（多智能体社会仿真）和 OpenStory（角色沙盒演化）不同，本项目走的是证据链路线：逐条伏笔 → 约束图 → 逻辑传播 → 一致性验证。

🔬 核心方法
  1. 伏笔结构化：将前80回中的每一条伏笔与脂批按统一格式录入（回目、类型、置信度、关联人物、关联事件）
  2. 约束图构建：建立伏笔之间的逻辑关系——必然导致、支持、矛盾/互斥、时间顺序、因果依赖
  3. 约束传播：给定一条伏笔为真，自动传播其对其他伏笔/结局的影响
  4. 一致性验证：检查一组结局假设是否与所有已知约束兼容，发现矛盾
  5. 拓扑排序：基于时间顺序约束对事件进行排序，重建后三十回的事件序列

约束类型说明

🔗 必然导致：前提成立时结论必然成立（如"脂批明确指出秦可卿淫丧天香楼" → "原稿非病死"）

✅ 支持：前提增加了结论的可信度（如"冷月葬花魂" → 支持沉湖说）

❌ 矛盾/互斥：两个结论不能同时为真（如"'万苦不怨'的黛玉之死" 与 "程高本焚稿断情"矛盾）

⏱️ 时间顺序约束：事件A必须在事件B之前发生（如元春之死 → 贾府之败）

🔀 因果依赖：事件A是事件B的前提条件（如元春失宠 → 贾府失去政治保护）

🤝 如何贡献

这个项目的核心资产是数据，而不是代码。每一条你录入的伏笔、补全的人物结局、添加的约束关系，都在直接增加整个系统的推理能力。

📝 贡献方式一：添加伏笔

在 data/foreshadowing.json 中添加新条目，格式如下：

{
  "id": "FS-031",              ← 递增ID
  "chapter": 34,               ← 回目（1-80）
  "section": "情中情因情感妹妹",
  "type": "文本伏笔",          ← 类型：文本伏笔|脂批批语|谶语判词|命名谐音|物事象征|梦境预兆|戏曲点题|对话暗示
  "content": "原文或批语...",
  "context": "解读...",
  "evidenceType": "前80回文本伏笔",  ← 证据类型
  "confidence": "极有可能",    ← 确定|极有可能|有可能|存疑
  "relatedCharacters": [{"id":"CHAR-XX","name":"人物名"}],
  "relatedEvents": [{"id":"EVT-XXX","name":"事件名"}],
  "source": "出处说明",
  "contributor": "你的GitHub ID"
}
📝 贡献方式二：添加约束

在 data/constraints.json 中添加新约束，连接已有的伏笔/人物/事件：

{
  "id": "CST-0019",
  "type": "支持",              ← 必然导致|支持|矛盾/互斥|时间顺序约束|因果依赖
  "sourceForeshadowing": "FS-XXX",
  "targetForeshadowingOrFate": "CHAR-XX",
  "rationale": "你的推理依据...",
  "strength": "强（极可能）"    ← 刚性|强|弱
}
📝 贡献方式三：补全人物

在 data/characters.json 中添加新人物（如鸳鸯、平儿、司棋等又副册人物），或为现有人物补充新的伏笔引用和替代结局理论。

📝 贡献方式四：改进推理引擎

Python 推理引擎位于 src/core/engine.py，欢迎为以下能力贡献代码：

  • 更精确的约束传播算法（带权重的概率传播）
  • 多假设对比（同时评估多个替代结局方案的一致性得分）
  • 自动伏笔发现（用NLP从原文中检测潜在的伏笔文本）
  • 可视化约束图（D3.js或Mermaid生成依赖关系图）
  • 连接到MiroFish/OpenStory的约束注入接口
📋 提交规范
  1. Fork 本仓库，在分支上进行修改
  2. 伏笔内容必须是前80回原文或脂批原文，不可自行编造
  3. 每条伏笔/约束需提供出处（版本、回目、批语位置）
  4. 约束推理需写明逻辑依据（为什么A能推出B）
  5. 发 PR 时附上简短说明
  6. 不确定的地方标注 "confidence": "存疑"
